# Saldo dashboard

Static one-page dashboard for the Art House Saldo bot (HTML + CSS + JS, no build step).

- Data comes from a read-only, key-protected API (`saldo-dashboard-api` Edge Function); this repository holds no data and no secrets.
- Open the site with the access link: `https://<pages-url>/#k=<key>` (the key is stored in the browser and removed from the address bar).
- Languages: Uzbek (default) and Russian.
